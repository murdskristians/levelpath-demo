# Plan: Edit a draft purchase request

> Spec: agents/524be108/spec.md · Type: feature

## Approach

Add `PUT /purchase-requests/:id` beside `submit`, copying its pattern: look up by id and `requester_id` in `withTenant`, 404 if absent, 409 if not a draft, then an update conditional on `status = 'draft'`. On the web, make `NewRequestForm` accept an optional `initial` draft, so the same form serves both. The alternative, a second form component, would copy Suggest fields and validation.

### 2. API service and route

Service, after `create`:

```ts
/** The caller's own draft gets new field values. Not theirs or not found is a 404, not a draft a 409. */
update(user: AuthUser, id: string, input: UpdatePurchaseRequest): Promise<PurchaseRequest> {
  if (!isUuid(id)) throw new NotFoundException();
  return this.db.withTenant(user.tenantId, async (trx) => {
    const request = await trx
      .selectFrom('purchase_requests')
      .select(['id', 'status'])
      .where('id', '=', id)
      .where('requester_id', '=', user.userId)
      .executeTakeFirst();
    if (!request) throw new NotFoundException();
    if (request.status !== 'draft') throw new ConflictException('only a draft can be edited');
    let updated: { id: string } | undefined;
    try {
      updated = await trx
        .updateTable('purchase_requests')
        .set({
          supplier_id: input.supplierId,
          title: input.title,
          amount_cents: input.amountCents,
          currency: input.currency,
          category: input.category,
          description: input.description,
          updated_at: sql<Date>`now()`,
        })
        .where('id', '=', id)
        .where('requester_id', '=', user.userId)
        .where('status', '=', 'draft')
        .returning('id')
        .executeTakeFirst();
    } catch (err) {
      // The composite foreign key to suppliers: unknown, or another company's.
      if (isKeyViolation(err)) throw new NotFoundException();
      throw err;
    }
    if (!updated) throw new ConflictException('only a draft can be edited');
    return readBack(trx, id);
  });
}
```

Controller (import `Put`, `updatePurchaseRequestSchema`, `UpdatePurchaseRequest`):

```ts
@Put(':id')
update(
  @CurrentUser() user: AuthUser,
  @Param('id') id: string,
  @Body(new ZodValidationPipe(updatePurchaseRequestSchema)) body: UpdatePurchaseRequest,
): Promise<PurchaseRequest> {
  return this.purchaseRequests.update(user, id, body);
}
```

## Notes

- Nest runs the body pipe before the handler, so a bad body is 400 even for an unseen id. The same already holds for decision.
- No migration. Do not touch `db/` or any file in `protected_paths`.
- Never leave a `catch` empty. The one in `update` rethrows.
