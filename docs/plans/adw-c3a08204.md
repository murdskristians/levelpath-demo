# Plan: Edit a draft purchase request

> Spec: agents/c3a08204/spec.md · Type: feature

## Approach

Add `PUT /purchase-requests/:id` that reuses the create schema and the `submit` pattern: select the caller's own row (404 if absent), refuse a non-draft (409), then update conditionally on `status = 'draft'`. In the web app, reuse `NewRequestForm` with an optional `initial` request instead of building a second form, and add an Edit button to the draft rows. A new schema or a PATCH would add a second validation path for no gain, because the form always sends every field.

None. No new package. (Existing: NestJS 12 ESM, Zod 4 `z.strictObject`, Kysely, Vitest, React 19.)

### 2. API

Service, `update`, placed after `submit`. Add `UpdatePurchaseRequest` to the type import.

```ts
  /** The caller's own draft gets new field values. Not theirs or not found: 404. Not a draft: 409. */
  update(user: AuthUser, id: string, input: UpdatePurchaseRequest): Promise<PurchaseRequest> {
    if (!isUuid(id)) throw new NotFoundException();
    return this.db.withTenant(user.tenantId, async (trx) => {
      const request = await trx
        .selectFrom('purchase_requests')
        .select(['id', 'status'])
        .where('id', '=', id)
        .where('requester_id', '=', user.userId)
        .executeTakeFirst();
      if (!request) throw new NotFoundException();
      if (request.status !== 'draft') throw new ConflictException('only a draft can be edited');
      let updated: { id: string } | undefined;
      try {
        // Conditional on the status, so a concurrent submit can't be overwritten.
        updated = await trx
          .updateTable('purchase_requests')
          .set({
            supplier_id: input.supplierId,
            title: input.title,
            amount_cents: input.amountCents,
            currency: input.currency,
            category: input.category,
            description: input.description,
            updated_at: sql<Date>`now()`,
          })
          .where('id', '=', id)
          .where('requester_id', '=', user.userId)
          .where('status', '=', 'draft')
          .returning('id')
          .executeTakeFirst();
      } catch (err) {
        // The composite foreign key to suppliers: unknown, or another company's.
        if (isKeyViolation(err)) throw new NotFoundException();
        throw err;
      }
      if (!updated) throw new ConflictException('only a draft can be edited');
      return readBack(trx, id);
    });
  }
```

The key-violation abort rolls the transaction back, so nothing is written (criterion 6).

Controller: add `Put` to the `@nestjs/common` import, `type UpdatePurchaseRequest, updatePurchaseRequestSchema` to the shared import, and:

```ts
  @Put(':id')
  update(
    @CurrentUser() user: AuthUser,
    @Param('id') id: string,
    @Body(new ZodValidationPipe(updatePurchaseRequestSchema)) body: UpdatePurchaseRequest,
  ): Promise<PurchaseRequest> {
    return this.purchaseRequests.update(user, id, body);
  }
```

`PUT` answers 200 by default. Check the CORS and proxy config in `apps/api/src/main.ts` and `apps/web/vite.config.ts` for a method allow-list; add `PUT` if there is one.

```tsx
const save = async (input: Parameters<typeof api.updateRequest>[1]) => {
  if (!editing) return;
  setError(null);
  if (
    await run(
      () => api.updateRequest(editing.id, input),
      () => undefined,
    )
  ) {
    setEditing(null);
    await loadMine();
  }
};
```

The create form shows when `formOpen && !editing`. The New request button shows when `!formOpen && !editing`. `onEdit={(r) => { setFormOpen(false); setEditing(r); }}`. Never put the edited values into state from the response except by `loadMine`.
